1. **Problem** — templates scattered; personal copies drift from approved versions.
2. **Open the portal** — chat-first Template Hub.
3. **Search** — “Find the latest MOM template” → approved version + alternatives.
4. **Version history** — “Show version history for design document”.
5. **Create** — “Create a QMM proposal” → agent asks 3–4 questions → generates `.docx`.
6. **Download** — open the Word file; show filled placeholders.
7. **ACL** — switch user to `joiner`, try creating QMM proposal → denied write.
8. **Analytics** — side panel shows most-used / stale templates.
9. **AWS path** — Bedrock + OpenSearch/S3 when moving off laptop demo.
